# Final hg38 and identification results

This snapshot contains final hg38 reconstruction metrics for three models at
14 lengths, identification results for both locus-sampling modes and attack
arms, and 42 embedding-geometry analyses with provenance. Publication metadata
and the figure sources used by the revised paper are included.

Large checkpoints, raw inputs, per-sequence dumps, and alignment work directories
are excluded. Archived cluster checkout paths in JSON were made relative to the
repository; scientific values and source digests were preserved.
